# Поиск по изображениям

Стек: `sklearn`, `keras`, `tensorflow`, `torch`, `transformers`, `seaborn`, `numpy`, `ppandas`, `ResNet50`, `pandas`, `SentenceTransformer`


__Описание проекта:__ 

Фотохостинг для профессиональных фотографов «Со Смыслом» (“With Sense”) обладает отличительной особенностью — описание может предоставить не только тот, кто размещает фотографию, но и другие пользователи портала. Суть поиска заключается в следующем: пользователь сервиса вводит описание нужной сцены, а мервис выводит несколько фотографий с такой же или похожей сценой.

__Цель исследования:__

разработать демонстрационную версию поиска изображений по запросу пользователя.<br>Необходимо отфильтровать запрос в связи с ограничением: _поисковым сервисам и сервисам, предоставляющим возможность поиска, запрещено без разрешения родителей или законных представителей предоставлять любую информацию, в том числе, но не исключительно тексты, изображения, видео и аудио, содержащие описание, изображение или запись голоса детей_.

__Ход исследования:__
<br><br>
- Подготовка данных: загрузка датафреймов, получение общей информации;
- Предобработка данных: обработка пропусков, поиск аномалий;
- Исследовательский анализ: построение распределений и зависимостей в данных;
- Векторизация изображений и запросов;
- Обучение модели, предсказание на тестовых векторизированных данных.

__Основные выводы:__

В качестве целевой метрики была принята RMSE. С использованием сети с лучшим набором параметров было выполнено тестирование: поступал запрос, модель определяла изображение с наивысшим совпадением с описанием. Визуальный анализ соответствия пары "изображение-описание" показал крайне низкое качество работы модели на тестовых данных. Для сравнительной оценки эксперимент был повторен с загруженной моделью CLIP-ViT, который показал высокое качество предсказаний.
